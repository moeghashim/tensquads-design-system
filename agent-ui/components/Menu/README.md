A menu floats from an icon button: `surface-elevated` fill, `radius-xl`, `shadow-overlay` plus `shadow-hairline`, 6px padding, items 32px tall with a 14px glyph in `text-secondary` and a 14px label. A separator is a `border` hairline bleeding to the edges. Destructive actions are `danger-text`, always last, always after a separator.

The consumer provides the items; the menu closes on outside click and Escape. **Don't**: put more than six items in one menu, or two danger items.
