A distribution shows how one whole splits: for a branch node, how many runs went down each branch. Each group is the node's name with its tile, one 10px stacked bar whose segments are separated by 2px of ground and shaded from `gray-500` down in the order given, and a key beneath listing each part with its count in bold.

Segments are greys because branches have no fixed identity colour; the key, not the shade, names them. Order parts largest first so the darkest segment is the most common path.
